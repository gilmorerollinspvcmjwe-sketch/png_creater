# 游戏 UI 素材自动抠图工具

AI 游戏 UI 素材自动抠图工具 —— 上传 AI 生成的素材合集图，自动识别背景并抠成透明底，自动拆分独立素材，支持人工确认后导出。

---

## 功能特性

- **多背景支持**：白底、纯色底（洋红/绿幕/蓝幕）、棋盘格假透明、真实透明 PNG、深色渐变背景
- **自动背景识别**：智能采样边缘像素，自动判断背景类型
- **手动取色**：点击背景任意位置取色，精准去除目标颜色
- **自动素材识别**：基于 Alpha 遮罩找连通区域，支持近距离碎块合并
- **人工修正**：删除、重命名、单图下载候选素材
- **一键导出**：透明 PNG + manifest.json + preview.html，打包 ZIP 下载
- **本地浏览器处理**：无需上传服务器，保护素材隐私

## 核心参数说明

| 参数 | 说明 | 默认值 | 建议值 |
|---|---|---|---|
| **容差** | 背景颜色相近范围，越大去除范围越广 | 80 | 纯色底 50-100，深色底 100-200 |
| **去边强度** | 去除白边/粉边程度 | 15 | 边缘脏时 30-40 |
| **合并距离** | 分散元素合并为同一素材的像素距离 | 24px | 密集排列 8-15px，稀疏排列 30-50px |
| **最小面积** | 过滤小噪点 | 1000px | 大图 2000+，小图 500 |
| **安全边距** | 裁切后保留外边距 | 12px | 按需调整 |

### 参数调整指南

- **背景残留多** → 增大容差
- **素材边缘被吃掉** → 减小容差
- **该分开的合并了** → 减小合并距离
- **该合并的拆开了** → 增大合并距离
- **细小碎片多** → 增大最小面积
- **深色背景图** → 使用"点击背景取色"功能最准确

## 支持的输入类型

| 类型 | 说明 | 效果 |
|---|---|---|
| 真实透明 PNG | 已有 Alpha 通道 | 直接保留，自动识别素材 |
| 纯白底图 | 背景接近白色 | 自动去除 |
| 纯色底图 | 洋红/绿幕/蓝幕等 | 自动识别常见颜色并去除 |
| 棋盘格假透明 | AI 画的灰白格子 | 自动检测两组格子颜色并去除 |
| 深色渐变底 | 深灰/黑色纹理背景 | 建议用"点击取色"手动处理 |

## 输出格式

### 1. 透明 PNG 单图

每个素材导出为独立 PNG，真实透明背景。

```
pet-title-plaque.png
pet-mood-happy.png
quest-panel-parchment.png
```

### 2. manifest.json

```json
[
  {
    "name": "pet-mood-happy",
    "file": "pet-mood-happy.png",
    "width": 158,
    "height": 156,
    "sourceX": 1200,
    "sourceY": 820,
    "sourceWidth": 158,
    "sourceHeight": 156
  }
]
```

### 3. preview.html

包含浅色/深色背景双预览，方便检查边缘质量。

### 4. ZIP 包

```
asset-cutout-export.zip
├─ images/
│  ├─ pet-title-plaque.png
│  └─ pet-mood-happy.png
├─ manifest.json
└─ preview.html
```

## 技术栈

- **前端**：原生 HTML + CSS + JavaScript（无框架依赖）
- **图像处理**：Canvas API + OffscreenCanvas + Web Worker
- **打包工具**：Vite
- **导出 ZIP**：JSZip
- **全部本地处理**：无服务器依赖

## 核心算法流程

```
读取图片像素
  ↓
判断背景模式 / 采样边缘颜色
  ↓
生成背景掩码（Mask）
  ↓
背景像素 alpha = 0，主体保留
  ↓
边缘去边处理
  ↓
基于 Alpha 生成二值掩码
  ↓
膨胀处理，合并近距离碎块
  ↓
找连通区域
  ↓
过滤小噪点和贴边残片
  ↓
加安全边距裁切
  ↓
输出候选素材
```

## 已知限制

1. **密集排列素材**：间距 < 10px 时可能合并或拆分不准，需手动调整合并距离
2. **复杂渐变背景**：自动模式可能采样不准，建议使用"点击取色"
3. **素材本身有大片镂空**：如边框中间的空洞，可能被误认为是多个素材
4. **半透明边缘**：当前为二值遮罩，边缘为硬切，暂不支持平滑羽化
5. **不做人像级 AI 抠图**：仅针对游戏 UI 素材板优化
