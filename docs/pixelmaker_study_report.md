## 二、核心算法深度对比

### 2.1 背景检测算法

#### pixelmaker 方案：边缘 BFS + 轮廓墙

**流程：**
```
1. 用户标注背景色 + 轮廓色（如黑色外轮廓）
2. 像素分类：
   - 接近轮廓色 → 标记为"墙"(2)
   - 接近背景色 → 标记为"背景候选"(0)
   - 其他 → 标记为"前景"(1)
3. 从图片四边开始 BFS flood fill：
   - 只穿过"背景候选"像素
   - "墙"像素阻止传播
4. 没被 flood fill 到的 → 确认为前景素材
5. 形态学闭运算（膨胀+腐蚀）桥接小间隙
6. 8-连通区域检测，提取独立素材
```

**关键代码逻辑：**
```javascript
// 像素分类
for (每个像素) {
  if (接近轮廓色) → mask=2 (墙)
  else if (接近背景色) → mask=0 (背景候选)
  else → mask=1 (前景)
}

// BFS 从边缘确认背景
从四边所有背景候选像素开始 BFS
墙像素阻止传播
被访问到的 → 确认背景(0)
没被访问的候选 → 实际是前景(1)
```

**优势：**
- 即使素材内部有和背景相似的颜色，也不会被误删（因为被轮廓墙挡住）
- 能处理"背景色和素材深色部分相近"的情况
- 用户控制精确（标注背景色+轮廓色）

**劣势：**
- 需要用户手动标注两种颜色
- 没有轮廓的素材无法使用此模式

#### 本项目方案：颜色距离阈值

**流程：**
```
1. 自动采样边缘像素或用户取色
2. 计算每个像素与背景色的欧氏距离
3. 距离 < 容差 → 背景
4. 距离 ≥ 容差 → 前景
5. 膨胀处理（合并近距离碎块）
6. 4-连通区域检测
```

**关键代码逻辑：**
```javascript
// 像素分类
for (每个像素) {
  distance = sqrt((r-bgR)^2 + (g-bgG)^2 + (b-bgB)^2)
  if (distance < tolerance) → 背景
  else → 前景
}
```

**优势：**
- 自动识别，用户操作简单
- 支持多种预设（白底、洋红、棋盘格等）

**劣势：**
- 当"背景色"和"素材深色部分"颜色相近时，会误删素材
- 没有"轮廓墙"概念，背景可能"渗入"素材边缘

### 2.2 形态学处理对比

#### pixelmaker：双掩码策略（聪明）

```javascript
// 掩码 A（原始）：用于最终像素提取
// 掩码 B（闭运算后）：仅用于连通性分析

// Step 1: 在原始掩码上做膨胀/腐蚀（用户控制）
// Step 2: 创建闭运算掩码（桥接小间隙）
// Step 3: 在闭运算掩码上找连通区域（不会把一个素材拆成多个）
// Step 4: 从闭运算区域的边界框内，提取原始掩码中的前景像素
// Step 5: 从已找到的像素出发，BFS 扩展到相邻的原始前景像素
```

**效果：**
- 闭运算掩码确保"一个素材不会被拆成多个"
- 原始掩码确保"提取的像素是精确的，不会多拿"

#### 本项目：单掩码膨胀

```javascript
// 只在原始掩码上做膨胀
const dilatedMask = dilateMask(mask, width, height, Math.floor(mergeDistance / 2));
// 然后在膨胀后的掩码上找连通区域
```

**效果：**
- 膨胀会把素材之间的间隙填满，防止一个素材被拆开
- 但也会把真正应该分开的素材合并在一起
- 没有"精确像素恢复"步骤，膨胀后的边缘就是最终边缘

### 2.3 内轮廓抠图对比

#### pixelmaker：区域级二次 BFS

**流程：**
```
1. 用户勾选需要内抠的区域
2. 在每个区域内，标注"内部背景色"和"内部轮廓色"
3. 在该区域的边界框内：
   a. 像素分类（内部背景/内部轮廓墙/前景）
   b. 从边界框边缘开始 BFS，标记连通的内部背景
   c. 没被 BFS 到的内部背景 → 被内轮廓包围的"洞"，保留为前景
   d. 被 BFS 到的 → 从边缘渗入的背景，删除
4. 可选：膨胀/腐蚀微调边缘
```

**适用场景：**
- 木框中间的空白区域
- 角色眼睛、嘴巴等内部细节
- UI 面板的镂空区域

#### 本项目：无此功能

目前只有"去除背景"功能，没有对"已检测到的素材区域"进行二次处理的能力。

## 四、具体可学习的技术点

### 4.1 最值得引进的："轮廓墙"概念

**问题场景：**
用户上传的 AI 生成图通常有这句话提示词：
> "白色背景，游戏素材细的黑色外轮廓"

素材有黑色外轮廓，但我们的算法看不到这个轮廓。当我们用"颜色距离"判断背景时：
- 白色背景 → 距离小 → 正确识别为背景
- 黑色轮廓 → 距离大 → 正确识别为前景
- 素材内部深色区域 → 距离也大 → 正确识别为前景
- **但素材边缘的阴影/过渡色 → 距离中等 → 可能误判**

如果引入"轮廓墙"：
- 黑色轮廓 = 墙，阻止背景判断的"渗透"
- 即使素材边缘颜色接近背景，也不会被错误删除

### 4.2 次值得引进的：双掩码策略

**当前问题：**
- 合并距离太小 → 一个素材被拆成多个碎片
- 合并距离太大 → 多个素材被合并成一个

**双掩码方案：**
- 掩码 A（精确）：用于最终提取像素
- 掩码 B（闭运算）：仅用于判断"哪些像素属于同一个素材"
- 这样即使素材中间有镂空（如藤蔓缠绕），闭运算能把它们连起来，但提取时仍然是精确的

### 4.3 值得引进的：内轮廓二次抠图

**当前问题：**
- 大方框素材中间有大片空白（镂空）
- 我们的算法会把外框和内部空白当成两个独立素材
- 或者如果合并距离大，会把它们合并成一个（但内部空白被填满了）

**内轮廓方案：**
- 第一步：检测外轮廓，得到素材整体区域
- 第二步：在素材区域内，检测内部背景色，去除内部的"洞"
- 结果：外框是完整的，内部是透明的

### 4.4 不太需要引进的

| 功能 | 原因 |
|---|---|
| 单文件 HTML | 我们的模块化架构更适合维护和扩展 |
| 手动矩形选框 | 我们已有自动检测，手动选框使用频率低 |
| 像素画工具 | 超出本项目范围 |

```
3. Worker 中修改 irregularDetect：
   - 如果提供了轮廓色，先标记轮廓像素为"墙"(2)
   - BFS 时墙像素阻止传播
   - 最终提取时，墙像素归为前景
4. 流程：取背景色 → [可选]取轮廓色 → 开始检测
```

**预期效果：**

### P2（中优先级）：引入双掩码策略

**实现方案：**
```
1. 在 irregularDetect 中：
   - mask = 原始分类结果
   - closedMask = 对 mask 做闭运算后的结果
2. 在 closedMask 上找连通区域（不会把一个素材拆开）
3. 对每个连通区域：
   - 收集 closedMask 中该区域的所有像素坐标
   - 从这些坐标出发，在原始 mask 中 BFS 扩展，只收集 mask=1 的像素
   - 得到精确的素材像素集合
```

**预期效果：**
- 解决"藤蔓素材中间有镂空被拆开"的问题
- 不需要调大合并距离，也不会误合并相邻素材

### P3（中优先级）：引入内轮廓二次抠图

**实现方案：**
```
1. 异形检测完成后，显示"内轮廓抠图"按钮
2. 用户选择要处理的区域（多选）
3. 用户取"内部背景色"（如木框中间的深灰色）
4. 用户取"内部轮廓色"（可选）
5. 对每个选中的区域：
   - 在区域边界框内，用内部背景色做 BFS
   - 内部轮廓色当墙
   - 被 BFS 到的 → 删除（外部渗入的背景）
   - 没被 BFS 到的 → 保留（被内轮廓包围的"洞"）
```

**预期效果：**
- 大方框素材中间空白变成透明
- 角色素材的眼睛/嘴巴内部背景被去除

### P4（低优先级）：优化批量处理

- 当前批量处理只做了"背景去除"，没有"素材识别"
- 可以增加批量模式下的"自动拆分素材"功能

## 六、技术细节补充

### 6.1 BFS 边缘 flood fill 的数学原理

为什么从边缘 BFS 比全图阈值更准确？

**假设：**
- 图片背景是连通的（通常成立，因为素材板四周都是背景）
- 素材被背景包围（通常成立）

**全图阈值的问题：**
```
背景色 = RGB(30,30,30)
素材 A 边缘阴影 = RGB(55,50,45) → 距离 35 < 容差 80 → 误判为背景
素材 B 深色部分 = RGB(40,35,30) → 距离 15 < 容差 80 → 误判为背景
```

**边缘 BFS 的优势：**
```
1. 从四边开始，只能传播到"与背景相连通"的区域
2. 素材 A 被轮廓墙包围，BFS 无法渗入
3. 素材 B 内部的深色像素虽然像背景，但与外部背景不连通
4. 所以它们不会被 flood fill 到
```

### 6.2 闭运算（Closing）的作用

**定义：** 先膨胀后腐蚀

**目的：**
- 膨胀：把分离的小碎片连起来
- 腐蚀：恢复原始边缘（不扩大素材边界）

**例子：**
```
原始掩码（藤蔓素材）：
  █ █   ← 两片叶子，中间有空隙
  █ █

膨胀后：
  ███   ← 空隙被填满
  ███

腐蚀后（闭运算结果）：
  ███   ← 仍然连通，但边缘比膨胀后精确
  ███
```

### 关键学习点

1. **"轮廓墙"是最核心的创新** - 用轮廓色作为物理屏障，解决了颜色判断的根本缺陷
2. **"双掩码"是工程上的聪明做法** - 连通性分析和像素提取分开，各自最优
3. **"边缘 BFS"比"全图阈值"更可靠** - 利用"背景连通性"这一先验知识

### 建议的改进顺序

1. 先引入"轮廓墙"功能（解决当前用户反馈的"模糊"问题）
2. 再引入"双掩码"策略（解决"素材被拆分/合并不当"的问题）
3. 最后引入"内轮廓抠图"（解决"大方框中间空白"的问题）
