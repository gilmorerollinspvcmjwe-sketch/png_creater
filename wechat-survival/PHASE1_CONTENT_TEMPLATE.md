## 1. 任务模板

### 1.1 主线任务模板

```markdown
【主线任务】{任务名称}

任务ID: MAIN_{序号}
类型: main
优先级: P0

{任务描述（2-3 句话介绍背景和目标）}

【任务目标】
- {目标 1}
- {目标 2}

【前置条件】
- {前置任务 ID}（如有）
- {等级要求}
- {物品要求}

【任务奖励】
- 经验值：{数值}
- 物品：{物品名称 × 数量}
- 功能解锁：{解锁功能}

【流程节点】
1. {触发条件} → {给予任务}
2. {完成目标} → {提交任务}
3. {奖励发放}

────────────────
[接受任务]
```

```markdown
【任务奖励】

```

## 2. NPC 模板

### 2.1 NPC 结构模板

```markdown
ID: NPC_{类型}_{序号}
名称: {NPC 名称}
类型: {商人|任务 giver|幸存者|特殊|敌对}
位置: {出现位置}
对话风格: {描述}

【背景】
{2-3 句话背景介绍}

【可发布任务】（任务 giver 专属）
- {任务 ID}：{任务名称}
- {任务 ID}：{任务名称}

【可交易物品】（商人专属）
| 物品 | 价格 |
|------|------|
| {物品} | {价格} |

【好感度系统】
- 初始好感：{数值}
- 提升方式：{方式}
- 能力解锁：{条件} → {能力}

【特殊对话】
- 初次见面：「{对话内容}」
- 好感度高：「{对话内容}」

【招募条件】（幸存者专属）
- {条件 1}
- {条件 2}

【特殊能力】
- {能力名称}：{能力描述}
```

### 2.2 NPC 示例

```markdown
ID: NPC_MERCHANT_01
名称: 流浪商人汤姆
类型: 商人
位置: 避难所门口（随机出现）
对话风格: 幽默、奸诈

【背景】
汤姆是废土上最精明的商人之一，居无定所，四处漂泊。
他总是能搞到一些稀罕货，但价格嘛...你懂的。

【可交易物品】
| 物品 | 价格 |
|------|------|
| 食物×10 | 弹药×5 |
| 水×10 | 药品×2 |
| 药品×5 | 食物×15 |
| 绷带×3 | 水×10 |

【好感度系统】
- 初始好感：0
- 提升方式：完成交易 +5，赠送物品 +10
- 能力解锁：好感度 50+ → 神秘商品

【特殊对话】
- 初次见面：「嘿，幸存者！我叫汤姆，这片废土上最精明的商人！想买点什么？」
- 好感度高：「汤姆我最近搞到了一批好货，第一个想到的就是你！够义气吧！」

【出现条件】
- 随机：每 3-5 天出现一次
- 必定：主线任务期间
```

### 3.4 事件示例

#### 探索事件示例

```markdown
【探索事件】废弃超市

事件ID: EXPLORE_01
类型: explore
子类型: resource
触发条件: 探索「避难所周边」区域

你发现了一家废弃超市，货架上还有一些物资。
超市内部似乎有人活动过的痕迹，地上散落着一些杂物。

【场景细节】
- 货架倾斜，商品散落一地
- 收银台抽屉开着，像是被人翻过
- 门口有干涸的血迹

────────────────
【选项】
1. 搜索物资（获得食物×5, 水×3）- 有风险
2. 谨慎搜索（获得食物×2, 水×2）- 无风险
3. 离开（无收获，无风险）

请回复数字选择行动
```

#### 战斗事件示例

```markdown
【战斗】丧尸围攻！

事件ID: BATTLE_04
类型: battle
难度: ★★★
触发条件: 探索「城市废墟」时 30% 概率触发

一群丧尸发现了你！他们步履蹒跚，但数量众多，
为首的一只似乎比其他更快，更具威胁。

【敌人配置】
- 普通丧尸 ×5
- 敏捷型丧尸 ×1

【玩家状态】
❤️ 生命值：80/100
⚡ 体力：45/50
🧪 绷带：2

【特殊机制】
- 敏捷型丧尸会在第 3 回合优先攻击

────────────────
【选项】
1. 正面战斗（消耗体力，击杀所有敌人）
2. 边打边撤（损失部分资源，安全撤离）
3. 全力逃跑（必定逃脱，消耗 1 个绷带）

请回复数字选择行动
```

## 4. 数值规范

### 4.1 资源数值

| 资源类型 | 单次获取范围 | 存储上限 | 备注 |
|----------|-------------|---------|------|
| 食物 | 2-10 | 100 | 基础资源 |
| 水 | 2-10 | 100 | 基础资源 |
| 药品 | 1-3 | 50 | 稀有资源 |
| 弹药 | 5-20 | 200 | 战斗资源 |
| 废铁 | 3-15 | 200 | 建造资源 |
| 木材 | 3-15 | 200 | 建造资源 |
| 瓶盖 | 10-100 | 9999 | 货币 |

### 4.2 任务奖励

| 任务类型 | 经验奖励 | 货币奖励 | 物品 |
|----------|---------|---------|------|
| 主线任务 | 100-500 | 50-200 | 必定 1-2 件 |
| 支线任务 | 50-200 | 20-100 | 概率 1 件 |
| 日常任务 | 20-50 | 10-30 | 概率物品 |

| 敌人类型 | 生命值 | 攻击力 | 特殊能力 |
|----------|-------|--------|---------|

| 匪徒 | 40 | 10 | 远程攻击 |

## 5. 编写检查清单

### 任务检查

- [ ] ID 唯一且符合规范
- [ ] 描述清晰，无错别字
- [ ] 目标明确，可量化
- [ ] 奖励合理，与难度匹配
- [ ] 前置条件合理
- [ ] 流程逻辑正确

### NPC 检查

- [ ] ID 唯一且符合规范
- [ ] 背景故事完整
- [ ] 对话风格一致
- [ ] 数值合理
- [ ] 好感度系统完整（可选）

### 事件检查

- [ ] ID 唯一且符合规范
- [ ] 描述生动，有氛围感
- [ ] 选项平衡，各有优劣
- [ ] 奖励/惩罚合理
- [ ] 触发条件明确
- [ ] 难度与游戏阶段匹配
