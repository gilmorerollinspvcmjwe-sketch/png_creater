# WeChat Survival - Phase 1 玩法详细设计

> **文档版本**: v1.0  
> **阶段**: Phase 1 玩法验证  
> **周期**: 4-6 周  
> **核心策略**: 玩法优先，AI 赋能  
> **目标**: 用人工内容验证核心玩法是否好玩

---

## 1. Phase 1 概述

### 1.1 核心目标

| 目标 | 指标 | 测量方式 |
|------|------|----------|
| 验证核心玩法循环是否有趣 | 任务完成率 >70% | 后台统计 |
| 验证微信 UI 交互是否流畅 | 平均游戏时长 >15分钟/天 | 后台统计 |
| 收集玩家反馈数据 | NPS 净推荐值 >30 | 问卷调查 |
| 建立内容模板和标准 | 模板库完整 | 人工评审 |
| 确定产品方向 | 次日留存 >40% | 后台统计 |

### 1.2 战略原则

> **"先做出好玩的游戏，再用 AI 放大价值"**

Phase 1 不追求 AI 技术，而是专注于：
1. **核心玩法是否有趣** - 探索→战斗→建设→成长的循环是否吸引人
2. **微信 UI 是否流畅** - 消息推送/菜单/面板交互是否自然
3. **数值是否平衡** - 难度曲线是否平滑，资源是否稀缺得恰到好处
4. **内容是否丰富** - 20+ 任务、10+ NPC、30+ 事件是否够玩

### 1.3 交付物清单

| 交付物 | 数量 | 优先级 |

## 2. 游戏背景设定

### 2.1 世界观

```
世界设定：全球穿越到"生存游戏空间"
主角身份：房间之主（觉醒系统者）
核心目标：升级房间、收纳NPC、对抗怪物、探索无限世界
核心冲突：爽文成长 vs 对抗性挑战 | 资源有限 vs 无限探索

全新设定：
- 每个人醒来都在一个独立房间（room_xxx）
- 有系统金手指，但也有定时怪物突袭
- 强大的 NPC 玩家（其他房间管理者，可能是敌人）
- 无限探索：房间→走廊→楼层→区域→世界→多维空间
- 赛季系统：每90天一个赛季，重置部分进度
```

### 2.2 时间设定

| 参数 | 值 | 说明 |
|------|-----|------|
| 游戏内时间流逝 | 1 天 = 10 分钟现实时间 | 每天触发日常事件 |
| 房间等级上限 | 无限（Lv1-Lv100+） | 可持续升级 |
| 当前时间点 | 穿越后第 1 天 | 游戏开始 |

### 2.3 地图设定（无限探索区域）

| 区域 | 危险等级 | 资源类型 | 解锁条件 |
|------|---------|---------|----------|
| 房间 | ★☆☆☆☆ | 基础物资 | 默认 |
| 走廊 | ★★☆☆☆ | 材料 | 房间 Lv2 |
| 楼层 | ★★★☆☆ | 稀有物资 | 房间 Lv3 |
| 建筑 | ★★★★☆ | 高级物资 | 房间 Lv5 |
| 区域 | ★★★★★ | 限定物资 | 房间 Lv7 |
| 世界 | ★★★★★★ | 终极奖励 | 房间 Lv10 |
| 多维空间 | ∞ | 无限可能 | 房间 Lv20+ |

### 2.4 怪物突袭系统

| 突袭类型 | 频率 | 强度 | 应对方式 |
|---------|------|------|---------|
| 丧尸潮 | 每 7 天 | 简单-中等 | traps/武器/NPC战斗 |
| 掠夺者 | 随机 | 中等 | 防御设施/盟友支援 |
| 神秘组织 | 每 30 天 | 困难 | 顶级装备/NPC战队 |

### 2.5 NPC 玩家系统

| 类型 | 行为 | 威胁等级 | 应对 |
|------|------|---------|------|
| 友好玩家 | 交易/合作 | 无 | 建立联盟 |
| 中立玩家 | 互不干涉 | 低 | 保持距离 |
| 敌对玩家 | 掠夺/攻击 | 高 | 防御/反击 |
| 霸主玩家 | 控制区域 | 极高 | 联合其他玩家 |

## 3. 核心玩法循环

### 3.1 玩法循环图

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            核心玩法循环                                       │
│                                                                             │
│    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐           │
│    │   探索   │───▶│ 战斗/收集 │───▶│ 返回避难所│───▶│ 建设/升级 │           │
│    └──────────┘    └──────────┘    └──────────┘    └──────────┘           │
│         │                                                │                 │
│         │                                                │                 │
│         ▼                                                ▼                 │
│    ┌──────────┐                                    ┌──────────┐           │
│    │  事件触发 │◀──────────────────────────────────│ 招募幸存者 │           │
│    └──────────┘                                    └──────────┘           │
│         │                                                │                 │
│         │                                                ▼                 │
│         │                                        ┌──────────┐              │
│         └────────────────────────────────────────│ 更强的探索 │              │
│                                                  └──────────┘              │
│                                                                             │
│  循环强化：随着避难所升级和幸存者增加，玩家可以探索更危险的区域，获得更好的资源 │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 玩法循环说明

| 阶段 | 时长 | 核心操作 | 获得 |
|------|------|----------|------|
| 系统提示 | 即时 | 接收任务/事件 | 目标明确 |
| 收集资源 | 1-2 分钟 | 探索/采集 | 食物、水、材料 |
| 收纳 NPC | 1-2 分钟 | 对话/招募 | 美女伙伴、战斗助手 |
| 房间升级 | 1-2 分钟 | 建设/强化 | 更大空间、更多功能 |
| 战斗防御 | 即时 | 怪物突袭/玩家对抗 | 战利品、经验 |

### 3.3 每日节奏

| 时间段 | 游戏状态 | 事件类型 |
|--------|----------|----------|
| 早上 | 探索为主 | 资源发现事件 |
| 中午 | 战斗为主 | 遭遇敌人事件 |
| 下午 | 混合 | 随机事件、任务刷新 |
| 夜间 | 突袭高发 | 怪物进攻事件 |

## 9. 测试计划

### 9.1 测试流程

```
Phase 1 测试流程
═══════════════════════════════════════════════════════════

第 1-3 天：内部测试
  ├── 团队成员体验完整流程
  ├── 记录卡点和问题
  └── 快速迭代修复

第 4-10 天：小范围测试（5-10 名玩家）
  ├── 发放测试资格
  ├── 收集行为数据
  └── 收集主观反馈

第 11-12 天：数据分析
  ├── 分析留存曲线
  ├── 分析任务完成率
  └── 提取关键问题

第 13-19 天：迭代优化
  ├── 根据反馈调整数值
  ├── 优化 UI 交互
  └── 增加/修改内容
```
