## 🎮 游戏玩法

### 第一步：接受主线任务

1. 点击底部导航栏的 **「任务」**
2. 找到 **「第一天：基础生存」**
3. 点击 **「接受任务」**

### 第二步：开始探索

1. 点击底部导航栏的 **「消息」**
2. 确保选中 **「废土探索」** 聊天
3. 点击下方快捷按钮：
   - **周边拾荒** - 低风险，获得基础资源
   - **深入废墟** - 中风险，可能获得稀有资源
   - **返回基地** - 结束探索

### 第三步：管理资源

1. 点击底部导航栏的 **「避难所」**
2. 查看当前资源储备
3. 升级设施（需要足够资源）

### 第四步：查看角色状态

1. 点击底部导航栏的 **「背包」**
2. 点击 **「查看详情」** 打开角色面板
3. 查看生命值、饱食度、口渴度、体力

## 🎯 核心系统说明

### 消息系统

- **消息通知** - 系统重要预警
- **求生大楼群** - 模拟其他玩家聊天
- **废土探索** - 主要玩法入口
- **我的避难所** - 基地建设信息
- **任务列表** - 任务进度追踪
- **流浪商人** - 限时交易事件

### 任务系统

**主线任务**（5 个）:
- MAIN_01: 第一天：基础生存
- MAIN_02: 第三天：清理周边
- MAIN_03: 第五天：寻找幸存者
- MAIN_04: 第十天：医疗设施
- MAIN_05: 第三十天：解药线索

**支线任务**（示例）:
- SIDE_01: 寻找干净水源
- SIDE_02: 囤积粮食
- SIDE_06: 清除变异体

### 资源系统

| 资源 | 用途 | 获取方式 |

| 💧 水 | 维持生存 | 探索、任务奖励 |

## 💡 游戏技巧

### 新手建议

1. **优先完成主线任务** - 解锁核心功能
2. **合理分配资源** - 不要一次性用完
3. **定时查看通知** - 避免错过重要事件
4. **升级防御设施** - 应对丧尸潮
5. **多与 NPC 互动** - 解锁更多玩法

### 资源管理

- 每日消耗：食物×2/人，水×1/人
- 建议储备：至少 3 天的资源
- 升级优先级：防御 > 农场 > 电力 > 水处理

### 探索策略

- **前期**（Lv1-5）: 以周边拾荒为主，避免高风险
- **中期**（Lv5-10）: 开始深入废墟，收集稀有资源
- **后期**（Lv10+）: 挑战高难度区域，寻找解药线索

## 🐛 常见问题

### Q: 游戏无法加载？
A: 检查浏览器控制台是否有错误，确保 npm 依赖已正确安装。

### Q: 存档丢失？
A: 游戏使用 localStorage 自动保存，清除浏览器数据会导致存档丢失。

### Q: 如何重置游戏？
A: 打开浏览器开发者工具 → Application → Local Storage → 删除 `wechat-survival-phase1-storage`

### Q: 通知推送不显示？
A: 确保浏览器允许通知权限，检查是否被浏览器拦截。

## 🔌 开发者模式

### 查看游戏状态

打开浏览器控制台，输入：

```javascript
// 查看完整游戏状态
console.log(usePhase1Store.getState())

// 查看资源
console.log(usePhase1Store.getState().resources)

// 查看任务
console.log(usePhase1Store.getState().quests)

// 手动添加资源（测试用）
usePhase1Store.getState().addResource('food', 100)
```

### 修改游戏数据

```javascript
// 直接修改状态
usePhase1Store.getState().setResources({ food: 999, water: 999 })

// 完成所有任务
usePhase1Store.getState().quests.forEach(q => {
  usePhase1Store.getState().acceptQuest(q.id)
  usePhase1Store.getState().completeQuest(q.id)
})
```
