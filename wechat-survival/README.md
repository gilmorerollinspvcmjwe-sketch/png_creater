## 🎮 游戏简介

**全新世界观：生存游戏空间**

全球穿越到"生存游戏空间"，每个人醒来都在一个独立房间。有人欢喜有人愁——有人开局就断粮，有人却觉醒了系统金手指。而你，恰好是那个觉醒系统的幸运儿！

这不是简单的爽文...
- 🔥 **定时怪物突袭** - 尸潮/掠夺者/神秘组织轮番进攻
- ⚔️ **强大 NPC 玩家** - 其他房间管理者，可能是敌人  
- 🌍 **无限探索** - 房间→走廊→楼层→区域→世界→多维空间
- 💎 **收纳 NPC** - 美女助手、战斗伙伴、商人、工匠

微信生存游戏是一款融合**微信社交界面**与**爽文生存玩法**的创新游戏。你将扮演一名**房间之主**，通过微信式的聊天界面与 NPC 交流、探索升级、收纳伙伴，在怪物横行的世界中生存下去！

### 核心特色

| 特色 | 说明 |
|------|------|
| 🔄 **微信 UI** | 100% 还原微信聊天界面，零学习成本 |
| 🏃 **摸鱼玩法** | 碎片化时间，随时可停，适合上班摸鱼 |
| 🌆 **开放世界** | 多个区域等待探索，无限可能 |
| ⚔️ **对抗性** | 怪物突袭、其他玩家，危机四伏 |
| 👩‍🔧 **伙伴系统** | 结识 NPC，招募女仆，组建生存团队 |
| 📈 **爽文成长** | 系统金手指，轻松变强，横扫一切 |

## 🎯 开发策略：玩法优先，AI 赋能

> **核心原则**：先做出好玩的游戏，再用 AI 放大价值

| 阶段 | 策略 | 周期 |
|------|------|------|
| **Phase 1** | 玩法验证 - 人工内容验证核心玩法 | 4-6 周 |
| Phase 2 | AI 辅助 - AI 生成内容，人工审核 | 6-8 周 |
| Phase 3-4 | AI 增强/原生 - 全面 AI 介入 | 14-18 周 |
| Phase 5 | 优化上线 - 性能优化、商业化 | 4-6 周 |

## 🤖 AI 原生特性

> WeChat Survival 采用**AI 驱动**的创新架构，让游戏世界真正"活"起来！

### 核心 AI 技术

| 特性 | 说明 |
|------|------|
| 🔮 **动态内容生成** | 任务、NPC、事件、物品均由大模型实时生成 |
| 🧠 **智能 NPC** | NPC 具有记忆、情感、目标驱动的自主行为 |
| 🌐 **世界演化** | 玩家行为影响世界走向，派系关系动态变化 |
| 📖 **RAG 知识库** | 基于向量检索的上下文感知生成 |
| 🛡️ **三层验证** | LLM 自检 → Schema 验证 → 业务逻辑验证 |

### AI 架构

```
玩家交互 → World Director → Agent 群体 → LLM 生成 → 内容验证 → 游戏世界
                              ↑
                        记忆系统 ← 世界事实库
```

### 成本优化

采用**分层调用策略**：97% 低成本模型处理日常任务，3% 高成本模型处理关键决策。

## 🕹️ 玩法说明

### 1. 探索废土

在「废土探索」频道输入指令，探索周边区域：
- **周边拾荒**: 低风险，获得基础资源
- **深入废墟**: 中风险，可能遭遇敌人或发现宝藏
- **返回基地**: 结束探索，平安归来

### 2. 资源管理

管理你的生存资源：

| 资源 | 用途 |
|------|------|
| 💧 水 | 维持生存，持续消耗 |
| 🍞 食物 | 补充饱食度，持续消耗 |
| 🪵 木材 | 升级设施，建筑防御 |
| ⚙️ 废铁 | 打造装备，维修设施 |
| 💰 瓶盖 | 货币，用于交易 |

### 3. NPC 交互

结识形形色色的废土居民：

- **老医生**: 治疗伤口，出售药品
- **铁匠老王**: 打造武器，修理装备
- **红狐狸**: 情报贩子，解锁隐藏任务
- **流浪商人**: 限时交易，获取稀有物资

### 4. 避难所建设

升级你的避难所设施：

- 🛡️ **防御工事**: 抵御丧尸潮攻击
- ⚡ **电力系统**: 解锁高级设施
- 🌾 **农场**: 持续产出食物
- 💧 **储水系统**: 储备饮用水

### 5. 角色成长

提升你的幸存者等级，分配属性点：

- 💪 **力量**: 增加战斗伤害，提升搬运上限
- 🏃 **敏捷**: 降低探索风险，提高闪避率
- 🧠 **智力**: 任务经验加成，解锁科技

## 🚀 快速开始

### 本地运行

```bash
# 克隆项目
cd wechat-survival

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 `http://localhost:3000` 即可开始游戏。

### 项目结构

```
wechat-survival/
├── src/
│   ├── stores/          # Zustand 状态管理
│   │   └── gameStore.ts # 全局游戏状态
│   ├── types/           # TypeScript 类型定义
│   │   ├── game.ts      # 游戏核心类型
│   │   └── gameplay.ts  # 玩法模块类型
│   ├── utils/           # 工具函数
│   │   ├── calculation.ts
│   │   ├── storage.ts
│   │   └── time.ts
│   ├── rules/           # 游戏规则引擎
│   └── App.tsx          # 主应用组件
├── index.html
├── package.json
└── vite.config.ts
```
