## Bug 严重级别定义

| 级别 | 说明 | 例子 |
|------|------|------|
| **Critical** | 导致游戏无法继续、数据丢失、安全问题 | 存档损坏、无法登录、货币负数 |
| **Major** | 严重影响游戏体验，但有绕过方法 | 关键任务无法完成、UI显示错误 |
| **Minor** | 小问题，不影响游戏进行 | 文字错误、动画卡顿 |
| **Enhancement** | 改进建议，非缺陷 | UI优化、体验改进 |

---

## 优先级定义

| 优先级 | 说明 | 响应时间 |
|--------|------|---------|
| **P0** | 必须立即修复 | 24小时内 |
| **P1** | 应该在下一版本修复 | 3天内 |
| **P2** | 应该在Phase 1结束前修复 | 1周内 |
| **P3** | 可以在后续版本处理 | 待定 |
